# Sécurité

## Ce que contient ce pack
Des instructions en texte pour un assistant IA et, selon le pack, de petits scripts Python locaux.
Aucun script ne se connecte à Internet, ne demande de mot de passe ou de clé, ni ne publie à votre place.

## Conseils
- Lisez les fichiers avant de les installer, comme pour tout outil trouvé en ligne.
- Laissez les demandes d'autorisation de votre assistant activées.
- Ne mettez jamais de mot de passe, de clé ou de donnée privée dans ces dossiers.

## Signaler un problème
Utilisez l'onglet **Security** du dépôt, puis **Report a vulnerability**. N'ouvrez pas d'issue publique
pour une faille. Seule la dernière version est suivie.
